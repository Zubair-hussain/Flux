# Delivery plan

1. Bootstrap repository and record the plan before implementation.
2. Build responsive homepage, safe URL validation, metadata inspection and download jobs.
3. Add stdio MCP server and Manifest V3 Chrome extension.
4. Add wireframes, policy documentation, unit/API/browser tests and coverage.
5. Validate production build and commit the finished implementation.

Runtime: a trusted, local Node server with yt-dlp and FFmpeg. Do not deploy as an unauthenticated public service. Platform availability and source resolutions vary. Sexual content is blocked using URL and source metadata; this MVP does not perform visual moderation.
